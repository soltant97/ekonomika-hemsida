# Ekonomika DS AB – hemsida

Statisk flerspråkig hemsida (svenska + engelska) för Ekonomika DS AB.

- Svenska sidor: `index.html`, `tjanster.html`, `om-oss.html`, `kontakt.html`
- Engelska sidor: `en/`
- Gemensamt: `style.css`, `script.js`, logotyper och favicon

Öppna `index.html` i en webbläsare för att se sidan. Inget bygge krävs.
